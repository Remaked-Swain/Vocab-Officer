# Policy Catalog

This compact catalog supports fail-open discovery. It is not a substitute for
the source documents returned by the router.

| Task tag | Primary scope |
| --- | --- |
| `vocabulary` | canonical headword, persistence and setless registration |
| `intake` | registration and paste intake |
| `testing` | session selection, grading and correction |
| `review-ui` | review grid, cards and accessibility |
| `correction` | meaning parsing and correction credit |
| `ocr` | image recognition and source numbering |
| `mastery` | consolidation, promotion and retirement |
| `multiple-choice` | choices, distractors and persisted format |
| `cloudkit-bootstrap` | initial upload and mirrored-store migration |
| `cloudkit-reconciliation` | import, audit and store notifications |
| `cloudkit-recovery` | replicas and explicit recovery |
| `cloudkit-authority` | mutation leases and authoring authority |
| `ios-sync` | iPhone hydration and learning facts |
| `memory-aid` | Gemini generation and caching |
| `performance` | measurable latency and large-fixture acceptance |
| `concurrency` | actors, cancellation and legacy GCD migration |
| `repository-privacy` | secrets, local data and publish hygiene |
| `deletion` | tombstones, scrub and resurrection prevention |
| `harness` | routing, verification and Closed-Loop operation |

Use multiple tags for compound work. When no tag confidently describes the
request, inspect `Docs/ClosedLoop/INDEX.md` and repository ownership directly.
