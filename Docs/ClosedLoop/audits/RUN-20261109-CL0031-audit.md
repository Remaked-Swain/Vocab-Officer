# RUN-20261109-CL0031 Audit

## Decision

`APPROVE`

## Scope

Read-only review of spaced relearning, adaptive Mastered maintenance, Mixed
session rotation, candidate-cache invalidation, focused regression evidence and
the repository's pre-verification performance and architecture gate.

## Findings

- Mixed composition enforces six reference, four active-review and two due
  Mastered questions as strict caps. A word in multiple categories counts
  against every applicable cap, and broad fallback cannot bypass those caps.
- Application orchestration delegates quota, overlap and fallback semantics to
  the persistence-independent Domain policy instead of duplicating them.
- Mastered-to-Active edits and replay-based status changes invalidate word
  candidate caches. Set-membership caches retain a separate, narrower lifetime.
- The implementation and architecture record both permit English-to-Korean
  streaks to reduce active review priority without requiring both directions.
- Candidate preparation is linear, ordering is `O(n log n)`, selection is
  linear and auxiliary space is `O(n)`. No schema change, full attempt-history
  scan, quadratic candidate lookup or new main-thread/network work was added.
- Focused tests cover overlapping caps, reduced sessions, same-day uniqueness,
  date-boundary rotation, future-set exclusion and Mastered-to-Active cache
  refresh. The Release 10,000-word session-generation gate and both platform
  target builds passed without running the unrelated full test suite.

No blocking correctness, regression, data-safety, architecture, performance,
readability or test-credibility issue remains.
